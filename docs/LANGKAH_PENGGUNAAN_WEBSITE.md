# Langkah-Langkah Penggunaan Website UKK-SARPRAS

Panduan singkat step-by-step per role.

---

## Siswa / Pengguna

1. Buka website → **Login** (NISN + password). Jika belum punya akun, **Register** dulu lalu **Aktivasi** dengan kode dari admin.
2. Setelah login, muncul **Daftar Barang untuk Pinjam**. Pilih kategori atau cari barang.
3. Klik barang yang ingin dipinjam → isi **Form Ajukan Peminjaman** (jumlah, tanggal pinjam & kembali, tujuan, lokasi) → **Kirim**.
4. Cek **Riwayat Peminjaman** untuk status (menunggu / disetujui / ditolak / dipinjam / dikembalikan).
5. Jika disetujui, ambil barang ke petugas. Bisa **Cetak Surat Peminjaman** jika perlu.
6. Kembalikan barang ke petugas sesuai jadwal (petugas yang mencatat pengembalian di sistem).
7. Untuk masalah/kerusakan: **Buat Pengaduan** (pilih sarpras pernah dipinjam, judul, lokasi, deskripsi). Cek **Daftar Pengaduan** untuk status.
8. **Profile** → ubah data jika perlu. **Ganti Password** jika ingin ubah password.

---

## Guru

Langkah sama dengan **Siswa/Pengguna** (Login → Daftar barang → Ajukan peminjaman → Riwayat → Ambil/kembalikan ke petugas → Buat pengaduan → Profile). Guru dapat meminjam barang sekali pakai jika diatur di sistem.

---

## Petugas SARPRAS

1. **Login** → **Dashboard** (ringkasan peminjaman, pengembalian, pengaduan).
2. **Kelola data:** **Kategori** dan **Ruang** (tambah/edit). **SARPRAS** (tambah/edit barang + unit). **Trash** untuk data yang dihapus.
3. **Peminjaman:** Buka **Daftar Peminjaman** → **Setujui** atau **Tolak** pengajuan. Jika disetujui → **Handover** (pilih unit, upload foto kondisi) → barang siap diambil peminjam.
4. **Pengembalian:** **Scan Pengembalian** → input kode peminjaman → **Form Pengembalian** (tanggal, kondisi tiap unit: baik/rusak/hilang) → Simpan.
5. **Barang Hilang:** **Daftar Barang Hilang** → pilih kasus → **Selesaikan** (ditemukan atau ganti rugi).
6. **Pengaduan:** **Daftar Pengaduan** → ubah **Status** (diproses/selesai/ditutup), tambah **Catatan**.
7. **Maintenance** — tambah/edit catatan perbaikan. **Laporan** — Kerusakan, Asset Health.
8. **Profile** / **Ganti Password** jika perlu.

---

## Admin

1. Semua langkah **Petugas** (dashboard, kategori, ruang, sarpras, peminjaman, pengembalian, barang hilang, pengaduan, maintenance, laporan).
2. **Kelola User:** Menu **Admin** → **User** → tambah/edit user, **Import** user, **Assign Role**, **Aktivasi** akun Pengguna/Guru.
3. **Activity Log** — lihat log aktivitas, **Export** jika perlu.
4. **Laporan lanjutan:** **Damage Analytics**, **Asset Lifecycle** (hanya Admin).

---

*Ringkasan: Siswa/Guru = pinjam & pengaduan; Petugas = kelola barang + approve + pengembalian + laporan; Admin = semua akses Petugas + user + activity log + laporan analytics.*
