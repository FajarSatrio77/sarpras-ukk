🌐 Masuk Aplikasi

Pengunjung masuk → cek login → jika belum: Login/Register. Jika Pengguna/Guru dan belum aktivasi → halaman Aktivasi. Setelah login, redirect: Pengguna/Guru → Daftar Sarpras (pinjam), Admin/Petugas → Dashboard.

🔐 Autentikasi

Login: NISN + Password → valid? → aktivasi? → redirect role.

Register: Form → simpan user (is_activated: false) → redirect Aktivasi.

Aktivasi: Form kode → jika OK, is_activated: true.

📦 Alur Peminjaman

Daftar Sarpras → Pilih Barang → Form (jumlah, tgl, tujuan, lokasi) → Validasi (stok, double booking, max 7 hari siswa) → Simpan status: menunggu → Admin/Petugas: Approve/Reject. Jika Approve → disetujui → Handover (pilih unit + foto kondisi) → dipinjam → siswa bawa barang → lanjut ke Pengembalian.

↩️ Alur Pengembalian

Scan/input kode peminjaman → valid & status dipinjam? → Form pengembalian (tgl, kondisi per unit: baik / rusak_ringan / rusak_berat / hilang) → Simpan → status peminjaman dikembalikan, update stok & unit. Jika ada unit hilang → alur Barang Hilang (Ditemukan / Ganti Rugi).

📋 Alur Pengaduan

Pengguna/Guru buat pengaduan (sarpras pernah dipinjam, judul, lokasi, deskripsi) → status: menunggu. Admin/Petugas update status: diproses (tanggapi + catatan), selesai, atau ditutup.

⚙️ Admin & Petugas

Kategori, Ruang, SARPRAS (CRUD + Unit + Trash), User (Admin: CRUD, Import, Role, Aktivasi), Laporan (Kerusakan, Asset Health, Damage Analytics, Asset Lifecycle), Maintenance, Barang Hilang (resolve), Activity Log.
